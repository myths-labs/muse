## What's New

MUSE 3.6 makes day-to-day continuity portable between Codex and Claude Code.
Use either client alone, or save in one and resume the same role and Lane in the
other. The agent derives the recovery plan from your request and saved evidence.

### Continue with short commands

- `/resume strategy Lane A` restores the selected role and Lane.
- `/save` records useful progress without ending the conversation.
- `/bye` performs a formal, evidence-scoped closeout when requested.
- At observed context pressure, save, compact when supported, verify and continue.
  A percentage does not force a new conversation or a full history replay.

Projects that use Strategy for implementation keep that arrangement. Switching
clients does not switch roles. Existing closed Lanes keep their reopen rules.

### Guarded updates and reusable closeout evidence

The shared Python runtime checks native writer identity, checkpoint versions,
reviewed adoption and source coverage. Stale writers cannot overwrite a newly
claimed Lane through MUSE helpers. Unchanged closeout evidence can reuse its
receipt; changed code, validators or project mappings invalidate relevant proof.
Missing evidence remains explicitly incomplete.

### Install or upgrade

From the MUSE checkout, run the installer for the clients you use:

```bash
bash scripts/install.sh --tool codex --target /path/to/project
bash scripts/install.sh --tool claude --target /path/to/project
```

The installer preserves user policy and existing Claude hooks, adds relative
skill discovery links and stores private rollback receipts. Known original 3.5
workflows are backed up before upgrade. Unknown modifications stop installation
before managed files are replaced. Installation never claims or initializes a
Lane. Keep the returned receipt and use the documented rollback procedure if
needed.

Continuity requires Git and Python 3.7+ on a local macOS/Linux filesystem. Use a
client version that supports your selected model. Native Windows, network
filesystem durability and arbitrary writes outside the helpers are not certified.
Save/Bye validation is not product QA, and automatic compaction is not a guarantee
of lossless memory.

### Verification

The public suite contains 44 installer and state regressions, including upgrade,
rollback, policy preservation, interrupted writes, concurrent initialization,
cross-provider adoption and closeout invalidation. CI runs the suite on Linux and
macOS. A separate native Codex → Claude Code → Codex exercise verified actual
session identities, saved decisions and a real file edit in an isolated project;
synthetic tests are not presented as native-client evidence.
