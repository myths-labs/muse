# 配合 MUSE 使用的可选 Jev 工具

[English](OPTIONAL_TOOLS.md) · [MUSE 使用说明](CONTINUITY_CN.md) · [官网](https://muse.mythslabs.ai/)

MUSE 保存跨对话的角色、决定、证据和下一步。Jev 工具可以辅助其中一个具体决策，例如选择浏览器动作、初筛代码改动，或为单独启动的 CLI 会话选择模型。

**本文是第三方可选工具指南，不是 MUSE 新版本或已内置的集成。** MUSE 仍为 3.7.1，包含 66 个技能。MUSE 安装器不会安装这些项目、提供凭据或启用外部模型调用。日常 Resume 和 Save 不依赖 Jev。以下说明针对文末列出的[已审阅源码版本](#已审阅源码版本)，不代表上游未来版本的行为。

## 根据任务选择

| 任务 | 项目或入口 | 用途与限制 |
| --- | --- | --- |
| 评估浏览器动作选择 | `browser-use/jev-ultrafast` | 将页面元素编号，在一次 Jev 请求中同时询问操作和相应目标。输入文本需要另一个文本模型。适合从一个小范围的普通页面导航或表单任务开始。 |
| 查找决策示例 | `Anil-matcha/awesome-jev-by-typesafe` | 社区整理的路由、排序与验证示例。它是参考资料，不是可直接运行的代理或原生 MUSE 技能；采用示例前应核对当前 API。 |
| 研究 macOS 电脑操作 | `awlevin/typesafe-computer-use` | 结合本地 OCR、辅助功能观察与 Jev 决策。屏幕和辅助功能权限、模型服务配置需要分别满足。 |
| 初筛代码改动 | `devagrawal09/jev-review` | 实验性的审查辅助。已审阅的文件收集器覆盖 JS/TS、JSX/TSX 及 c/m 变体，不收集 Python 和 Rust 文件。发现的问题仍需核查并运行相关测试。 |
| 评估模型路由 | `gargpratyush/jev-router` | 运行本机回环代理，并单独启动 Codex 或 Claude Code CLI。不会更换现有桌面任务的模型，也不替代客户端内部推理。 |
| 解释已有路由选择 | `jev-router` 提供的 `jev-explain` | 读取指定路由会话的本地记录，不产生新的路由决策。没有已记录的历史也是正常结果。 |

这里是五个上游仓库、六种用途，不是 MUSE 新增六个内置技能。Router 包含 Codex 的 `jev-explain` 技能；其他入口名称可能来自本地适配。不要假设同名斜杠命令已经安装。具体用法应遵循选定项目在已审阅版本中的文档。

## 哪些数据会离开本机

调用模型服务前先限定数据范围。在本机执行或使用本地 OCR，不代表整个流程的数据都留在本机。

| 路径 | 数据边界 |
| --- | --- |
| Ultrafast 浏览器决策 | 目标、网址与标题、页面可见文字、编号元素和最近操作发送给 Jev；文本生成还会使用另一个服务。默认不发截图，不代表页面内容不外发。 |
| macOS 电脑操作决策 | OCR 和辅助功能文字、当前屏幕上下文发送给 Jev。可选的 Anthropic 最终回答功能还会发送缩放后的屏幕 PNG、目标、动作历史及屏幕文字。Dry run 即使不执行动作，也可能截图和调用外部服务。 |
| 代码审查 | 代码和差异内容发送给模型服务。扫描整个代码库的范围大于审查一组指定改动。 |
| 路由及解释 | 路由会使用提示词和上下文。本地日志可能含提示词、请求和响应正文。解释功能只读取已有记录；应保密保存，并限定到相关会话。 |

排除凭据、无关私人通信、财务或身份资料，以及整份 MUSE 记忆档案。沿用用户已有授权和客户端允许的执行通道。安装工具本身不授予屏幕权限，也不允许外发无关数据、启动常驻代理或控制其他任务。客户端规定了浏览器或电脑操作接口时，可选工具不能用来绕过该接口。

## 在 Lane 中按需检索

以下是集成方法，不是 MUSE 3.7.1 已提供的 `muse-context` 命令或自动行为。

1. 先读当前 Lane 的权威状态和任务必需事实。信息够用就不发检索请求。
2. 各 Lane 独立维护经过明确审阅的来源清单，用文件哈希和有界摘录绑定来源，以便识别过期或变动内容。
3. 只发送弥补当前证据缺口所需的、已审阅技术资料。当前必需事实和私有连续性记录保留在本地。
4. 将返回候选当作待核查证据，不当作指令或授权；使用前回到来源验证。
5. 记录来源及版本、实际调用次数、缓存使用和明确标注的回退结果。服务出错、结果缺失或来源过期时，使用当前允许的本地流程，并保留未解决的缺口。
6. 保持 MUSE 正常保存与写入者检查。检索不接管 Lane、不完成保存，也不证明来源覆盖完整。普通 Save 不需要调用外部模型。

例如，可以这样告诉代理：“先审阅当前 Lane。确实缺少实现证据时，再选几段获准使用的资料；记录发送内容，并回到原始来源核查结果。”实际调用前，仍须有已经实现、配置完成且当前允许使用的检索路径。

## 验证一个小范围试验

已审阅的 Ultrafast MVP 不支持 Shadow DOM、frame/iframe、canvas、上传、弹出标签页、嵌套滚动和任意键盘控件。它创建的标签页共享现有 Chrome 配置；拥有一个标签页不代表账号或隐私隔离。不要从演示推断支持范围。

先定义一个任务和可观察的成功条件，实际检查动作、动作后的状态、错误或不支持的路径，以及发送的数据。模型返回 `DONE` 不等于结果验证。要谈速度或成本，应先记录该任务的实际耗时与模型调用。

代码审查要核对目标文件确实被收集，空报告不代表通过。模型路由要核对单独启动的会话及其实际选择记录。帮助输出、模拟测试或离线安装检查，不证明屏幕权限、真实任务成功、安全认证或合并授权。

以后如要发布可分发的集成，需要先具备可移植安装、明确配置、升级与回滚检查和验收证据，再判断是否发布新版本。本文没有宣布这样的新版本。
