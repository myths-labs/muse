What MUSE actually does

Markdown skills and project records, backed by a shared Python continuity runtime.

Project Memory

Lane checkpoints capture progress and evidence. Daily logs record events; long-term notes retain lessons. The agent reads the parts needed for the current work.

Your Role, Preserved

Keep your project's own division of work. If Strategy develops directly, it keeps doing so. Switching clients preserves the selected role and Lane.

Reviewed Handoffs

The receiving agent checks saved decisions, evidence gaps and the workspace before taking over. MUSE helpers reject saves from a previous writer after the Lane is claimed.

Reusable Closeout Evidence

An unchanged closeout can reuse its validated receipt. New work or changed evidence reopens the affected checks. Product readiness still needs its own acceptance tests.

66 Reusable Skills

Git workflows, debugging, security guard, coordinator mode, iterative retrieval, deep-dive analysis — pre-built skills your AI loads on demand.

Save and Continue

Save meaningful changes during work. At observed context pressure, save, compact when supported, then verify and continue. Recovery starts from persisted evidence; unsaved work needs checking.

Built for ongoing work

Continuity alongside the skills and tools you already use.

Install with a Way Back

The native installer preserves user policy and existing Claude hooks. Known 3.5 workflows are backed up; unknown modifications stop installation for review. Private receipts support rollback.

/sprint Pipeline

7-phase feature dev workflow: Think → Plan → Build → Review → Test → Ship → Reflect. Each phase loads the right skill automatically.

Git Security Guard

Pre-commit checks look for known secret patterns. Review remains necessary; private install receipts and prompt inboxes stay out of Git through installed ignore rules.

Online Dashboard

Visit muse.mythslabs.ai/dashboard — load your project, see roles, memory, skills visualized. 100% client-side.

Skill Manifest

One script indexes all 66 skills into manifest.json — name, category, size, assets. Machine-readable. CI-friendly --check mode catches stale indexes.

Evidence Boundaries

Missing sources remain incomplete. The agent checks gaps against available records instead of claiming perfect memory. Closed Lanes retain their recorded reopen conditions.

A lighter daily workflow

Resume when needed. Save progress. Keep building.

1. Resume your Lane

/resume strategy Lane A

The agent reviews the saved state and current workspace, then prepares goals and checks from your request.

2. Work and save

continue → /save → continue

Stay in the same conversation. Save decisions and results as the work progresses; formal Bye is optional.

3. Switch when useful

Save and stop the current writer. Resume the same role and Lane in the other client. Use /bye when you want a formal closeout.

Install for the clients you use

Local macOS or Linux · Git · Python 3.7+ · a client version that supports your model

1

Clone MUSE

git clone https://github.com/myths-labs/muse.git
2

Install Codex, Claude Code, or both

Run either command from the folder containing the cloned MUSE repository. Replace the project path; use the same path for both clients.

bash muse/scripts/install.sh --tool codex --target /path/to/your-project
bash muse/scripts/install.sh --tool claude --target /path/to/your-project

Existing policy and hooks are preserved. Keep the returned rollback receipt private. Review unknown local modifications before upgrading.

3

Open your project in your coding client

Resume an existing Lane with /resume strategy Lane A, or describe your new work. The agent prepares setup and acceptance checks. Restart the client if newly installed skills are not yet visible.

One system, three ways to work

Your role and project records follow the work.

ModeHow it worksWhat to keep in mind
One clientUse Codex or Claude Code for the whole task. Save meaningful progress and continue.No routine client switch or full Bye is required.
Switch clientsSave, stop the active writer, then resume the same role and Lane in the receiving client.The receiving agent reviews the workspace and missing evidence before taking over.
Parallel workUse separately scoped Lanes and isolated workspaces for independent work.Coordinate shared files and decisions. Writer checks do not protect arbitrary edits outside MUSE helpers.

Saving and compaction do not guarantee lossless memory. Missing sources stay incomplete, and product readiness needs its own tests. Native Windows and network filesystem durability are not certified.
