# /back — 回来（同义 `/回`，与 `/away`、`/托` 成对）

编排者收到时按下面做；其它线收到时只交本线的清单，并提醒用户去编排者那里过要定的事。单线项目由当前会话照做。

1. `date` 记下回来时间。读本线检查点里「用户离开（/away）」之后的各行，读额度（短窗、周）；问一下各线当前态（只问在跑的线，不叫醒空闲的大上下文会话）。
2. 先给用户「回来清单」，白话、先结论：
   - **做完了什么**（≤5 行，每行带证据位置：PR、版本号、文件）；
   - **替你做的决定**（每条一行：定了什么 + 一句理由）；
   - **要你定的事**（≤3 条，推荐放第一个；没有就写「没有」）；
   - **要你本人动手的事**（切账号、密码、证件、银行、签字、提交，一行）。
3. 要定的事用一次提问或下一步按钮问完，不分几轮零碎地问。
4. 检查点记「用户回来 HH:MM，托管结束」；编排者向各线发一句「用户已回来，要他定的事照常走编排者」。
5. 若额度已撞周墙、各线停着等切号：清单第一条就写「请切号」和顺序（照 `/handoff` 与接力手册）。
