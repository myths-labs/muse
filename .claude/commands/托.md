# /away — 托管模式（同义 `/托`）

用户说要离开（外出、睡觉、额度重置前不在）时执行。回来或醒来时用 `/back`（同义 `/回`）结束托管。单线项目照做，只是没有「各线」那几步；多线项目由编排者（`orchestrator`）统一排队。

## 收到后马上做（这一轮，用户还在线时）

1. `date` 记下离开时间；把「用户离开（/away）」和时间写进本线检查点（编排者写在自己检查点的当前节）。
2. 趁用户这一轮还在，先开好离开期间要用的会话：由定时或其它会话叫醒的轮次，客户端可能不允许开新会话，只能留卡片等用户点。用户的 `/away` 就是开这些会话的授权。额度还没重置时，新会话 brief 的第一步写「定时到重置后 +2 分钟，立刻结束本轮，什么都不读」，免得开工即撞墙。开出来的会话解开成顶层会话。
3. 编排者向现役各线发一条：「用户离开托管中：要用户定的事交编排者排队，别停下来等；先做不需要用户的」。其它线只告诉编排者。
4. 回用户一句：离开期间谁在做什么、几点会有什么结果、哪几件一定会等他回来。

## 离开期间：自己定、自己做（回来清单里报）

- 工程决定、排期、各线优先级、派子代理、开或归档已交接完的会话。
- 没有用户感知的修复与配置；项目规则允许范围内的小额测试花费。
- 用户事先已明确同意的事，照他原话的范围做，不扩大。
- 额度规则照旧：周额度到存档线就全局保存；撞墙后若切号必须用户本人操作，就停下等他回来，不硬撑。

## 一律等用户回来（放进回来清单，最多 3 条，每条带推荐）

- 没有事先同意的部署、生产数据变更、付款与明显花费、对外发消息或发布内容、删除数据。
- 价格、免费额度、上线范围与日期这类产品与商业决定。
- 必须本人做的：建账户、密码与两步验证、证件、银行信息、签字、接受条款、最后提交。
- 任何会公开用户住址或个人身份信息的选项。

## 打扰用户的唯一例外

线上宕机、钱或安全事故、数据外泄：发一条推送通知（一句话 + 已做的止损），其余一律不打扰。

## 用户回来（他的下一条消息）时

先按 `/back` 交「回来清单」，再回他的话；检查点记「用户回来 HH:MM」，结束托管。
